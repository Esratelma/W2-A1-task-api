# W2 A1 - Task API
## Project Description
This project is a simple REST API for managing a to-do task list.
The API supports the four CRUD operations:
- Create tasks
- Read tasks
- Update tasks
- Delete tasks
The application is built using Python and FastAPI.
The tasks are stored in an in-memory list, so the data will be lost when the server is restarted.

## Technologies Used
- Python 3.10+
- FastAPI
- Uvicorn
